# 系统蓝图

## 参考 GitHub / 开源项目后的抽象

成熟项目通常不是一次性生成内容，而是拆成稳定流水线：

1. **Research Ops**
   - 定时抓取多源信息。
   - 给信息打标签、去重、聚类。
   - 输出结构化 briefing。

2. **Trend / Opportunity Scoring**
   - 不只看热度，还看垂直相关性、受众痛点、平台适配、证据可视化。
   - 把“今天有什么热点”变成“今天什么值得拍”。

3. **Content Pack**
   - 每个选题必须有：核心观点、证据、反常识开头、分镜、标题、封面、发布简介。
   - 内容包比脚本更重要，因为它连接选题和生产。

4. **Production Pipeline**
   - 文案定稿后再生成 TTS。
   - 由 TTS 时间反推字幕和页面时长。
   - 画面服务论证，不做空泛氛围。

5. **Distribution / Feedback**
   - 发布包包括标题、简介、标签、评论区提问。
   - 复盘看 3 秒留存、完播率、互动、评论关键词。
   - 下一轮选题来自数据反馈。

## 本系统的最小闭环

```text
每日信号抓取
-> AI 垂直评分
-> 选题短名单
-> 内容包
-> v3 视频模板制作
-> 发布包
-> 复盘记录
-> 关键词和评分规则更新
```
