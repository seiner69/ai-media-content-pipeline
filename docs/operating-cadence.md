# 运营节奏

## 每日

1. 跑 `scripts/run_daily_pipeline.py`。
2. 看 `runs/YYYY-MM-DD/shortlist.md`。
3. 选择 1 个主选题，必要时手动补证据。
4. 生成或完善 `content_pack.md`。
5. 进入视频制作。

## 每周

1. 复盘本周所有视频：
   - 3 秒留存
   - 完播率
   - 点赞率
   - 收藏率
   - 评论关键词
2. 把高频评论写回 `config/ai_niche.json` 的关键词。
3. 删除无效选题方向。
4. 固化高表现视频结构。

## 每月

1. 更新账号定位。
2. 更新竞品账号列表。
3. 更新视频模板。
4. 复盘哪些选题能带来关注，哪些只带来泛流量。
