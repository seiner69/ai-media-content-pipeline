# GitHub / 开源参考

## AI-News-Briefing

启发点：每日自动 AI 新闻研究、结构化 briefing、多 agent 深度研究、Notion/Obsidian/Slack 分发。

系统借鉴：

- 每天固定运行。
- 输出结构化简报，而不是散乱链接。
- 支持深度研究模式。
- 研究结果进入知识库。

## n8n Content Trend Monitor

启发点：多平台趋势监控、机会分、内容日历、团队通知。

系统借鉴：

- 多源抓取。
- 趋势分析和内容机会分开。
- 结果写入可复盘的表格/文档。

## YouTube / Social Media Automation Agents

启发点：选题、脚本、视频、优化、发布的一体化工作流。

系统借鉴：

- 视频不是孤立生成，而是全流程的一环。
- 标题、缩略图、SEO、发布也要成为标准步骤。

## AI Faceless Video / ZJT / Toonflow 类项目

启发点：脚本、分镜、角色/画面、配音、视频合成分层处理。

系统借鉴：

- 先内容包，再视频工程。
- 分镜是中间层，不能从长文直接跳到视频。
